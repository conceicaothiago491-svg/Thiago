# Thiago — site pessoal

Site pessoal e portfólio de programação, feito com HTML e CSS.

## Estrutura

- `index.html` — página principal do site pessoal.
- `style.css` — estilos da página principal.
- `programacao/index.html` — portfólio de programação.
- `programacao/style.css` — estilos do portfólio de programação.

## GitHub Pages

Para publicar o site, configure GitHub Pages em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/(root)`. A página principal fica na raiz; o portfólio de programação ficará disponível em `/programacao/`.

## Personalização

Edite os arquivos HTML para alterar textos e links, e os arquivos CSS correspondentes para mudar a aparência. Os endereços de perfil e projeto apontam para o GitHub de Thiago.
